# 🤖 Многофункциональный Telegram-бот на Python

Этот проект создан для отработки навыков асинхронного программирования на Python и работы со сторонними API.

## 🛠 Стек технологий
*   **Python 3.x**
*   **Aiogram 3** (асинхронный фреймворк для Telegram-ботов)
*   **Aiohttp** (для асинхронных HTTP-запросов к API)
*   **python-dotenv** (для безопасного хранения токенов)

## ⚙️ Функционал
Бот имеет удобное меню (Reply-клавиатуру) и умеет:
1.  **📰 Показывать новости:** Запрашивает топ-5 новостей через NewsAPI и переводит их на русский язык (через MyMemory API).
2.  **🌤️ Показывать погоду:** По команде `/weather [город]` выдает текущую температуру, влажность и описание (через OpenWeatherMap).
3.  **🪙 Курс криптовалют:** Показывает актуальный курс BTC, ETH, SOL, ADA, DOGE и изменение за 24 часа (через CoinGecko API).
4.  **❓ Помощь:** Выводит список доступных команд.

## 🚀 Как запустить локально
1. Клонируйте репозиторий:
   `git clone https://github.com/Hensy4/telega_bot.git`
2. Установите зависимости:
   `pip install aiogram aiohttp python-dotenv`
3. Создайте файл `.env` в корне проекта и добавьте свои ключи:

BOT_TOKEN = ваш_токен_бота
NEWS_API_KEY = ваш_ключ_newsapi
WEATHER_API_KEY = ваш_ключ_openweather

4. Запустите бота:
`python main.py`

## 📈 Обработка ошибок
В коде реализована обработка исключений (`asyncio.TimeoutError`, `aiohttp.ClientError`), чтобы бот не падал при проблемах с сетью или неверном вводе пользователя.
